opt.hwnd	ウィンドウハンドル。数字のみは 10 進、0x 接頭辞または a-f を含む場合は 16 進。0x 推奨
opt.pid	プロセス ID。10 進かつ 0 より大きい値
opt.process	イメージファイル名（パスなし）、大文字小文字を区別しない。拡張子がない場合は .exe として扱う
opt.exe	イメージの完全パス、大文字小文字を区別しない
opt.title	ウィンドウタイトル完全一致
opt.title-contains	ウィンドウタイトルに部分文字列を含む
opt.title-regex	ウィンドウタイトルを正規表現で一致（ECMAScript 構文、解析時に検証）
opt.class	ウィンドウクラス名、大文字小文字を区別しない。例 Notepad / CabinetWClass
opt.index	n 番目のウィンドウを選ぶ。1 始まり、表示可否と Z 順で並ぶ
opt.newest	最後に作成されたウィンドウを選ぶ
opt.oldest	最初に作成されたウィンドウを選ぶ
opt.all	一致した各ウィンドウから 1 枚ずつ保存
opt.monitor	対象モニタの番号 1 始まり（ディスプレイ設定の順序）；primary = 主モニタ、all = モニタごとに 1 枚。ウィンドウ条件なしでは画面全体を、指定するとそのモニタに重なるウィンドウだけを撮ります。値は省略可（= primary）で後続引数を飲み込まないため --monitor out.png はそのまま出力先です。画面全体はデスクトップのピクセルなので必ず確認ダイアログを出し、--yes でも省略できません。モニタによるウィンドウ絞り込みは従来どおりウィンドウ画像です
opt.capture	wgc(既定、隠れても撮影可) / dwm(DWM サムネイル、隠れても撮影可) / printwindow(ウィンドウ自前描画) / bitblt(画面の可視ピクセルをコピー) / duplication(デスクトップフレームを矩形で切り出し) / auto(wgc-dwm-printwindow-bitblt の順にフォールバック；画面全体は wgc-duplication-bitblt)。ウィンドウ自身だけ: wgc / printwindow / dwm サムネイル。画面から取る: bitblt / duplication と dwm の画面フォールバック
opt.yes	ウィンドウ自身の画像だけを使う経路の確認を省略します。有効な画像を保証せず、権限・保護コンテンツ・エラー・上書き保護にも影響しません。画面からサンプルする経路（bitblt、duplication、画面全体のあらゆる経路、dwm の画面フォールバック）は必ずダイアログを出します。--yes=false は明示的に確認を
opt.out	出力パス。特殊値 - は画像バイトを標準出力へ書き込む。位置引数でも指定でき、パスを全く与えないと --out - と同じ。一括分の出力名は画面取得前にまとめて確定します。2 つのターゲットが同じ名前に 解決される場合はエラーになり、黙って上書きすることはありません。stdout には一度に 1 枚だけ出力できるため、複数のターゲットにヒットしたバッチはパラメータエラーとなり、1 枚も取得しません
opt.format	エンコード形式を指定。未指定なら出力ファイルの拡張子から判定し、それも判別不能なら png
opt.quality	JPEG の品質、既定 100
opt.no-overwrite	ターゲットが既に存在するなら上書きせずエラー終了（値を省略すれば禁止が有効）。--no-overwrite=false（0 / no / n / off）で禁止を取り消します。=true / 1 / yes / y / on は値を省略した時と同じ。複数指定した場合は最後のものが有効
opt.dry-run	解析と候補ウィンドウの列挙だけ行い、画面取得もファイル書き出しもしない
opt.json	廃止済みの互換スイッチで副作用なし：成功もエラーも元から JSON
opt.verbose	JSON に input 節（正規化された全入力）を追加し、notes も残す
opt.quiet	notes を省略。errors は常に返る
opt.lang	メッセージの言語。auto（既定、システム表示言語に従う）/ zh-CN / zh-TW / en / ja。未対応のシステム言語は en
opt.help	テキストのヘルプ（この部分）を出力
opt.version	バージョンと段階を出力

cli.monitor_value	--monitor には 1 以上のモニタ番号、または primary / all を指定してください
cli.monitor_value_hint	例: --monitor 1（1 台目のモニタ）/ --monitor primary（メイン）/ --monitor all（全モニタを 1 枚ずつ）
cli.monitor_conflict	--monitor all は「全モニタを 1 枚ずつ」という意味で、ウィンドウ条件なしのモニタ全体取得にしか使えません
cli.monitor_conflict_hint	モニタでウィンドウを絞り込む場合は単一の番号を指定してください。例: --monitor 2
match.monitor_out_of_range	--monitor のモニタ番号が存在しません
match.monitor_out_of_range_hint	この PC のモニタは %1 台です: %2
match.no_window_monitor_hint	--monitor %1 に絞り込みました。そのモニタにウィンドウが重なっているか確認してください
cap.unsupported_for_screen	%1 チャネルはウィンドウ自身の面を取得するため、モニタ全体には使えません
cap.unsupported_for_screen_hint	モニタ全体は wgc / duplication / bitblt、または auto を使ってください
cap.screen_rect_broken	このモニタの矩形が空のためピクセルを取得できません
cap.wgc.step.item_monitor	GraphicsCaptureItem.CreateForMonitor
cap.dup.no_adapter_outputs	GPU に列挙できるディスプレイ出力がありません
cap.dup.no_output_for_screen_hint	このモニタに対応する DXGI 出力が見つかりません（リモートセッションや仮想 GPU でよくある現象です）。wgc か bitblt を使ってください
note.dry_run_monitor	--dry-run：%1 台のモニタを選びました。画面取得もファイル書き出しもしていません

consent.denied_hint_desktop	何も撮影せず、ファイルも書きませんでした。この経路はデスクトップのピクセルを読むため --yes でも --quiet でも省略できません。一つのウィンドウだけなら wgc / printwindow / dwm に --yes を付けてください
