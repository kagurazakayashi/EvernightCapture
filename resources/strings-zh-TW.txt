opt.hwnd	視窗句柄。純數字按十進位，0x 前綴或含 a-f 按十六進位；推薦寫 0x
opt.pid	處理程序 ID，十進位且大於 0
opt.process	映像檔案名（不含路徑），忽略大小寫；無副檔名時按 .exe 處理
opt.exe	映像完整路徑，忽略大小寫
opt.title	視窗標題精確匹配
opt.title-contains	視窗標題包含子字串
opt.title-regex	視窗標題正則匹配，ECMAScript 語法，解析期即校驗
opt.class	視窗類名，忽略大小寫，如 Notepad / CabinetWClass
opt.index	取第 n 個視窗，從 1 開始，按可見性/疊放次序排序
opt.newest	取最後建立的視窗
opt.oldest	取最早建立的視窗
opt.all	每個匹配視窗各存一張
opt.monitor	截圖目標螢幕的編號，由 1 開始（按顯示設定裡的順序）；primary = 主螢幕，all = 每張螢幕各一張。不給視窗條件時 = 整張螢幕截圖，給視窗條件時 = 只算與該螢幕有重疊的視窗。取值可省略（= 主螢幕），省略時不吃後面的參數，所以 --monitor out.png 仍然可用。整張螢幕截圖會先彈框徵求同意，且沒有跳過確認的開關
opt.capture	wgc(預設，被遮擋也能截) / dwm(DWM 縮圖，被遮擋也能截) / printwindow(視窗自繪) / bitblt(拷螢幕可見像素) / duplication(桌面複製後按矩形裁) / auto(按 wgc-dwm-printwindow-bitblt 退回；整張螢幕只用 wgc-duplication-bitblt)
opt.out	輸出路徑；特殊值 - 表示把圖片位元組寫到標準輸出。也可用位置參數；完全不給時等同 --out -。整批輸出名在取影格之前一次算好，兩個目標算出同一個名字時整批報錯，不會靜默覆蓋。標準輸出一次只能交付一張影格，命中多個目標時整批報參數錯誤、一張都不截
opt.format	強制編碼格式；不給則由輸出檔案副檔名判定，副檔名也判不出時用 png
opt.quality	JPEG 品質，預設 100
opt.no-overwrite	目標已存在時不覆蓋，報錯退出（不給取值就是禁止覆蓋）；寫 --no-overwrite=false（0 / no / n / off）取消這條禁令，=true / 1 / yes / y / on 與不給取值同義。重複給出時最後一個生效
opt.dry-run	只解析並列出候選視窗，不截圖不寫檔案
opt.json	已廢棄的相容開關，無副作用：成功與錯誤本來就輸出 JSON
opt.verbose	JSON 中追加 input 段（正規化後的全部輸入），並保留 notes
opt.quiet	省略 notes；errors 無論如何都會返回
opt.lang	文案語言。auto(預設，跟隨系統顯示語言) / zh-CN / zh-TW / en / ja；系統語言不受支援時用 en
opt.help	輸出文字說明（本段）
opt.version	輸出版本與階段
